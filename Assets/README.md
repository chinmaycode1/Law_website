## Video and Fallback System

Your homepage now has an intelligent fallback system:

### How It Works:
1. **Video plays** → The static logo is hidden
2. **Video blocked/fails** → Static logo displays automatically
3. **Video ends** → Smoothly transitions to static logo

### Current Assets
- `advocate-logo-animation-final.mp4` - Hero section video animation
- `logo-fallback.svg` - Static logo displayed when video can't play or after it ends

### Optional Enhancement
You can still add a custom poster image if desired:
- Create `video-poster.jpg` (1920x1080px, 16:9 ratio, under 200KB)
- This will show briefly while video loads

The fallback logo features:
- Professional scales of justice design
- "ADVOCATE LAW FIRM" text
- Matches your site's color scheme
- Scalable SVG format (sharp at any size)
- Automatically displays if autoplay is blocked
